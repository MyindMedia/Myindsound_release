- **Goal:** Replace dead Supabase with Convex + R2 (slices 1 and 2) and ship the Three.js MiniDisc player on `stream.html`.
- **Architecture:**
  - Convex owns data, auth checks, Stripe/Clerk/GHL integration and R2 signing.
  - The browser uses `convex/browser` with Clerk tokens.
  - The player is a vanilla-TS module tree under `src/player3d/` rendering one Three.js canvas plus an HTML HUD.
- **Tech stack:**
  - Vite 7 multi-page + TS 5.9
  - Convex (+ `@convex-dev/r2`, `convex-test`)
  - Stripe 20, `@clerk/clerk-js` 5 (Clerk Backend REST from Convex)
  - three (npm), GSAP 3.12 (CDN), vitest, sharp, ffmpeg
- **Specs:**
  - `docs/superpowers/specs/2026-09-16-convex-backend-slice1-design.md`

### Task 1.3: Entitlements

### Task 1.4: Tracks + R2 signing

### Task 1.6: Fulfilment core (DB part)
